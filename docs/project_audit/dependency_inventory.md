# Dependency Inventory

## Python (Backend & AI)
- **FastAPI**: API routing and web server
- **Uvicorn**: ASGI server
- **Pydantic**: Data validation and serialization
- **Mesa**: Agent-based modeling framework (Wargame service)
- **SimPy**: Discrete-event simulation (Wargame service)
- **pgmpy**: Probabilistic graphical models (Bayesian Threat network)
- **Neo4j**: Graph database driver (Knowledge Graph service)
- **Pytest**: Testing framework

*Note: AI placeholders imply future requirements for PyTorch and FAISS.*

## Node / Frontend
- **React**: UI library
- **TypeScript**: Typed JavaScript
- **Vite**: Build tool and dev server
- **Axios**: HTTP client for API requests
- **Redux Toolkit (RTK)**: State management (`store/slices`)
- **Native WebSockets**: Used for alert streaming
